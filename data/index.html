Published
IEEE COMPAS 2025 · First author

Multi-Track Audio Fusion for Emotion Recognition Using Machine and Deep Learning Techniques

Can a machine tell how someone feels from their voice? This paper recognises emotion from speech by combining several audio tracks and comparing classical machine learning with deep learning models.

  • Data: labelled emotional speech recordings, split into training and test sets.
  • Features: audio features extracted from each recording and fused across multiple tracks.
  • Models: classical machine learning and deep learning approaches, compared on the same data.
  • Evaluation: accuracy and per-class results to see which emotions each model handles best.
